# Imágenes de NutriBalance

La landing usa una fotografía original generada con la herramienta integrada de imágenes de Codex el 14 de noviembre de 2026. Se creó para este proyecto y se convirtió a JPEG para reducir su peso de descarga. No representa a Mauricio Pelozo ni a pacientes reales.

- `plato-cotidiano.jpg` (370 KB): plato con vegetales, legumbres y cereales en una mesa de cocina. Composición vertical para el hero editorial.
- `food-line-art.png` (763 KB): ilustración original con contornos de frutas, verduras y hierbas, usada como textura tenue detrás de los pasos. Conserva transparencia.

**Dirección de generación:** fotografía editorial natural, cocina doméstica, alimentos de todos los días, luz realista, paleta verde bosque y marfil, sin texto, marcas, promesas de salud ni rostros identificables. Para el nuevo hero se pidió una toma cercana de un plato colorido, con foco en el alimento y fondo marfil.
